# سِجل — بوابة محاسبة مهنية

واجهة عربية ثابتة لمكتب محاسبة مهني، صُممت وفق اتجاه **«معيار هادئ»**: حداثة تحريرية، أزرق حِبري، ورق عاجي دافئ، ولمسات نحاسية مضبوطة. تركز الصفحة على عرض الخدمات، منهج العمل، والبدء بطلب مراجعة أولية.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

لإنشاء نسخة إنتاجية والتحقق من صحة TypeScript:

```bash
pnpm check
pnpm build
```

## المكوّنات

| المجال | التفاصيل |
|---|---|
| الواجهة | React 19 وTypeScript |
| التنسيق | Tailwind CSS 4 وقواعد تصميم مخصصة |
| الخطوط | IBM Plex Sans Arabic وDM Serif Display |
| الأصول | صور مخصّصة محفوظة في رابط التخزين الخاص بالمشروع |

> نموذج التواصل في الواجهة هو عرض أولي فقط، ويحتاج إلى ربط وسيلة إرسال حقيقية قبل استخدامه في الإنتاج.

## بنية المشروع

| المسار | الغرض |
|---|---|
| `client/src/pages/Home.tsx` | الصفحة العربية الرئيسية |
| `client/src/index.css` | نظام الألوان والطباعة والحركة |
| `ideas.md` | توثيق اتجاه التصميم المعتمد |
